IEEE 802.1Q: TAG, UNTAG & VLAN Nativa

Entendendo a Segmentação de Redes (IEEE 802.1Q)

O padrão IEEE 802.1Q define como um único switch físico pode isolar o tráfego em múltiplas redes locais virtuais (VLANs). Para garantir que os dados cheguem ao destino correto sem se misturar, o switch aplica conceitos fundamentais de tratamento de porta: UNTAG (Acesso), TAG (Trunk) e a VLAN Nativa.

Porta UNTAG 💻
Porta de Acesso

Conecta computadores e impressoras. Transmite dados limpos (sem tag).

Porta TAG 🏷️
Porta Trunk

Interconecta Switches e Roteadores. Mantém a etiqueta 802.1Q no cabeçalho.

VLAN Nativa ⚡
Exceção no Trunk

VLAN especial que trafega sem etiqueta dentro de um link Trunk.

Cabeçalho 802.1Q 📊
+4 Bytes Overhead

Insere TPID (0x8100), Prioridade (PCP) e o VLAN ID (1 a 4094).

📦 Anatomia do Pacote: Onde a TAG é inserida?

Veja como o cabeçalho IEEE 802.1Q altera a estrutura padrão de um quadro Ethernet, abrindo espaço para inserir 4 bytes de identificação (a "etiqueta") logo após os endereços MAC e antes do EtherType.

📮 A Analogia do Agente de Correios

Para fixar o funcionamento sem complicação, imagine que os pacotes de dados são cartas e os Switches são centrais de triagem dos Correios.

UNTAG

Carta do Destinatário (PC)

Você envia uma carta normal na caixa de correio local. A carta não tem etiquetas internas de triagem. Quando o carteiro entrega na sua casa, você recebe o envelope limpo. O dispositivo final (seu PC) só lê a mensagem.

Dispositivo final não precisa entender VLANs.
TAG

Malote do Caminhão (Trunk)

Para transportar cartas de vários departamentos (Financeiro, RH, Vendas) entre duas cidades, as centrais colocam cada lote dentro de malotes etiquetados ("Malote VLAN 10", "Malote VLAN 20"). O motorista do caminhão (porta Trunk) lê a etiqueta para saber onde descarregar.

Várias redes no mesmo cabo físico com identificador.
Nativa

Carta Solta no Caminhão

Se uma carta for jogada solta dentro do caminhão de transporte sem malote ou etiqueta nenhuma, os correios combinam uma regra: "Tudo o que chegar sem etiqueta deve ser jogado na caixa da Recepção Geral (VLAN Nativa)".

Usada para protocolos de gerenciamento e compatibilidade.

Mecanismo Interno: Ingress, Egress e Estrutura 802.1Q

A tomada de decisão de um switch gerenciável acontece em dois momentos distintos: na **Entrada (Ingress)** do pacote na porta e na **Saída (Egress)** para o cabo físico. Entender esta matriz de decisões elimina erros comuns de projeto de rede.

Matriz de Decisão: Como o Switch Processa o Tráfego

Tipo de Porta Tráfego Recebido (Ingress) Ação de Entrada Tráfego Enviado (Egress) Ação de Saída
UNTAGGED / Access Pacote Limpo (Sem Tag) Adiciona a Tag da VLAN de Acesso (PVID) internamente na memória. Pacote pertencente à VLAN da porta Remove a Tag (Untag) antes de entregar ao dispositivo final.
TAGGED / Trunk Pacote com Tag 802.1Q Verifica se o VID é permitido. Se sim, mantém o pacote na respetiva VLAN. Pacote de VLANs permitidas no Trunk Mantém a Tag (Tagged) com o VID correspondente no cabeçalho.
VLAN Nativa (no Trunk) Pacote Limpo (Sem Tag) no Trunk Atribui o pacote automaticamente à VLAN Nativa configurada. Pacote pertencente à VLAN Nativa Remove a Tag (Untag) ao transmitir pelo enlace Trunk.

🧩 Anatomia da Tag IEEE 802.1Q

Quando uma porta insere um Tag no cabeçalho Ethernet, ela expande o quadro adicionando exatos **4 Bytes (32 bits)** entre os campos MAC Address e EtherType original:

Campos do Cabeçalho 802.1Q (4 Bytes):
TPID (Tag Protocol ID): 16 bits (0x8100)
PCP (Priority Code Point): 3 bits (QoS / 802.1p)
DEI (Drop Eligible): 1 bit
VID (VLAN Identifier): 12 bits (VLANs 1 a 4094)
